# merge-sort

Merge Sort Implementation

A clean and efficient implementation of the Merge Sort algorithm in C++. 
Merge Sort is a stable, comparison-based, divide-and-conquer sorting algorithm with a time complexity of O(n log n).

📌 Features
✅ Stable Sorting (preserves the order of equal elements) 
✅ Divide-and-Conquer approach 
✅ Recursive & Iterative implementations 
✅ Time Complexity: O(n log n) 
✅ Space Complexity: O(n) (due to auxiliary array) 
✅ Supports custom comparators (for sorting objects)
